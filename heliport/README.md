# 🚁 場外離着陸場 AR

航空法第79条ただし書の許可を受けて設ける **場外離着陸場（ヘリコプター・陸上）** について、
着陸帯・進入表面・転移表面を iPhone のカメラ映像に重ねて表示し、現地で障害物の抵触を確認するためのアプリです。
iPhone のホーム画面に追加して使う単一ファイルの PWA で、外部ライブラリは使いません。

> **注意** 初期値は国交省通達「法第79条ただし書の規定による許可事務（場外離着陸場における離着陸の許可）」および
> AOPA Japan 掲載の基準図（回転翼航空機・一般）に基づく概略値です。実際の申請では最新の通達および航空局との
> 事前調整で基準を確認してください。本アプリは現地調査の補助であり、法的な適否を保証するものではありません。

## できること

| 画面 | 内容 |
|---|---|
| 📷 **AR** | カメラ映像の上に着陸帯・接地帯・進入表面（着陸側 / 離陸側）・物件制限表面・転移表面を半透明の面として描画。方位、中心までの距離、現在地の制限高を表示。📷 で重ね描きした画像を保存・共有 |
| 📐 **障害物計測（AR）** | ① 障害物の根元に照準 → ② 頂部に照準、の2回タップで、カメラ高さと俯角・仰角から水平距離と高さを算出し、その地点の制限高と比較して **OK / NG（突出量）** を判定。距離は手入力も可 |
| 🗺 **平面図** | 上から見た配置図（北を上 / 進入方向を上を切替）。障害物と自分の位置、スケールバー付き |
| 📐 **断面図** | 進入方向の縦断面（両側の進入表面、転移表面上端）と着陸帯中央の横断面（物件制限表面 → 転移表面）。障害物を棒で表示 |
| ⚠️ **障害物** | 方位・距離・高さの手入力で追加。一覧で判定結果を確認・削除 |
| ⚙️ **設定** | 着陸帯の位置（現在地で設定 / 緯度経度入力）、進入方位・離陸方位（進入経路と離陸経路のなす角 90°〜180° を任意に設定）、使用機の D′値、各表面の勾配・寸法、視野角、カメラ高さ、方位補正、JSON の入出力、計画概要のコピー |

## 表面モデル（初期値）

ローカル座標は「進入方位の前方 = x、右 = y、上 = z」。

| 要素 | 初期値 | 備考 |
|---|---|---|
| 着陸帯 | 長さ・幅 = **1.5 × D′** | D′ は回転翼を含む機体の最大投影寸法。飛行規程に大きい値があればそちらを入力 |
| 接地帯 | **0.83 × D′** | 着陸帯の中央 |
| 進入表面（着陸側） | 勾配 **1/4**、長さ 500 m、外側幅 200 m | 進入方位の反対側（機体が進入してくる側）に展開 |
| 進入表面（離陸側） | 勾配 **1/8**、長さ 500 m、外側幅 200 m | 離陸方位（空欄なら進入方位と同じ＝直進）の先に展開 |
| 物件制限表面 | 勾配 **1/2**、幅 10 m | 着陸帯・進入表面の側辺から外側へ |
| 転移表面 | 勾配 **1/1**、上端高さ 45 m | 物件制限表面の外縁から、上端高さに達するまで |

転移表面は着陸帯と両進入表面の合成外周をオフセットして生成しているため、進入表面の側辺では表面の高さに応じて帯幅が自動的に狭くなり、
進入経路と離陸経路が角度をなす場合もその内側・外側に連続して生成されます。重なる部分は低い方の表面が制限高になります。
すべての値は設定画面で変更でき、変更すると障害物の判定も再計算されます。

### 進入方向と離陸方向が異なる場合

設定の「離陸方位」に離陸時の機首方位を入れると、離陸側の進入表面はその方位へ展開します（なす角 90°〜180°、90° 未満は警告）。
離陸方向が着陸帯の辺に直交しない場合、離陸側の進入表面は**着陸帯を離陸方向に投影した幅**で着陸帯の縁から始め、
着陸帯との間にできる隙間は高さ 0 の面（着陸帯の延長）として扱います（安全側の近似）。

## 使い方（現地）

1. Safari で開き、共有 → **ホーム画面に追加**（カメラ・センサーは HTTPS でのみ動作します）
2. **設定** → 「📍 現在地を着陸帯の中心にする」で中心を記録（5 秒間で最も精度の良い GPS 値を採用）
3. **進入方位**（着陸時の機首方位）を入力するか、着陸方向を向いて「端末の向き」をタップ。離陸方向が異なる場合は **離陸方位** も入力
4. **使用機材** の D′値を入力
5. **AR** → 「カメラとセンサーを開始」。iPhone では「動作と方向」の許可ダイアログが出ます
6. 必要に応じて 🎚 で**視野角**を調整（既知の大きさの物が実物と合うように）
7. 📐 で障害物を計測、📷 で画像を保存

### 精度について

- 位置は iPhone の GPS（数 m 〜 十数 m の誤差）、方位は電子コンパス（数度の誤差）に依存します。進入表面の末端など遠方の表示は誤差が拡大します。設定の「方位補正」で磁気偏差や端末の癖を補正できます。
- iOS Safari は WebXR に対応していないため、カメラ映像の上に自前で投影する「擬似 AR」です。
- 障害物計測は地面が平らである前提です。カメラ高さ（初期値 1.5 m）は設定で変更できます。
- センサーが使えない環境（PC など）では「センサー無しで開始」でドラッグ操作により視点を動かせ、設定の「自分の位置：手動指定」で任意の地点からの見え方を確認できます。

## データについて

- 設定と障害物はこの端末のブラウザ内（localStorage）に保存されます。サーバー送信はありません。
- 設定画面の **JSON エクスポート / インポート** でバックアップ・別端末への移行ができます。
- 「計画概要をコピー」で中心座標・方位・寸法・障害物の判定一覧をテキストで取り出せます。
