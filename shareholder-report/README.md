# 📮 株主向け日報システム

カレンダーの予定と、オンライン会議の議事録（Google Meet の文字起こし・メモ）から、
**株主に送る簡潔な日報**を毎日つくるための仕組み。

## 全体の流れ

```
毎日 19:00
  ↓
[ Google Apps Script ]  カレンダー予定 + 議事録を自動収集
  ↓  Gmail（自分宛）
[ 素材メール ]  Claude への指示文つきのテキストが1通届く
  ↓  コピー & ペースト
[ Claude アプリ ]  簡潔型の日報を生成
  ↓  内容を確認（← ここが人の判断ポイント）
[ LINE ]  株主へ手動で転送
```

自動化するのは **素材集め** まで。日報の文面は Claude が書き、**送信は必ず人が確認してから**行う。
社内議事録には人事や未確定の資金調達の話が混ざるため、機械的に送信しない設計にしている。

## 生成される日報のかたち

**何時に、どこで、どんな話をしたか**を時刻順に並べ、最後に要点をまとめる形式。

```
📅 2026年09月08日(火) 日報

■ 10:00-11:00 Ｊ．フロントリテイリング様 訪問
　（品川シーズンテラス）
　今津様を訪問。
　※記録がなく、面談内容は日報に反映できていません

■ 15:00-16:00 マイクロアド京都支店様 ご紹介（オンライン）
　松山より同支店をご紹介いただき、京都支社との連携について
　意見交換。

■ 16:30-17:00 営業部門 責任者面談（オンライン）
　10月からの営業部の新体制と役割分担を確認。東京・京都の
　ヘリシャトルを北海道に次ぐ重点領域と位置づけ、営業を拡大
　する方針で合意。

■ デスクワーク
　午前中に見積・請求関連を代理店3社へ送付。午後は10月の
　新体制について社内調整を進めた。

──────────────
【本日の要点】
・10/1付で営業部を3課体制に再編
・東京の夜景フライトと関西空港・京都便の法人営業を強化
```

LINE で 1 通として読み切れる 400〜700 字。予定が 6 件以上ある日は、
時系列を 1 予定 1 行に圧縮して要点を厚くするよう指示している。

議事録が無い予定は無理に膨らませず「※記録がなく…」と明記させる。
書けることが無い行が並ぶのは、記録が残っていないという事実の表示でもある。

機微な話題（未確定の資金調達 / 人事・採用 / 係争・債権回収 / 拠点の存廃 /
事故・機材不具合 / 他社との未締結の交渉）は本文に入れず、末尾に
`※要確認:` として別掲される。載せるかどうかは送信者が決める。

**打ち合わせ先はカレンダーの予定どおりに実名で書く。**「提携先企業」「大手小売」
のように丸めない。誰と会ったかは株主が知りたい情報のため。社内の面談も、予定名に
社員の氏名が入っていればそのまま書く。

例外は**採用候補者**だけで、まだ社員でない個人の氏名は出さず「採用候補者との面接」
とする。本人の同意なく応募の事実を外部に伝えないため。

なお「誰と会ったか」と「その人の処遇」は別物として扱う。社員の氏名は本文に出す一方、
そこで話された評価・給与・処遇の内容は `※要確認` に回る。

文面のルールを変えたいときは `Config.gs` の `buildPrompt_()` を書き換える。

## 会議に出てこない作業も拾う

カレンダーだけを見ると、会議と会議のあいだが空白になる。実際にはそこで
見積を送り、契約書を返し、日程を調整している。そこで **Gmail の送信履歴**を
素材に含め、「デスクワーク」欄として日報に載せる。

取り込むのは**宛先・件名と、本文の冒頭 200 字**（`MAIL_BODY_CHARS`）。
件名だけでは何をしたか分からないことが多いためで、実際に

```
Re: 覺正です
Re: Space Aviation 11月月次報告
Re: エンジェル税制について
```

という件名の並びからは、それが遅刻の連絡なのか、定款の提出なのか、
株主からの問い合わせへの回答なのかが判別できない。一方で本文を全文入れると
金額の内訳や交渉条件まで混ざるため、用件が分かる冒頭だけに絞っている。
本文を一切入れたくない場合は `MAIL_BODY_CHARS: 0` にする。

日報に書くときは件名をそのまま並べさせず、用件のまとまりで要約させ、宛先は
社名・部署の粒度に丸める（会議と違い、メールの宛先は個人名を出さない）。日程調整や遅刻の連絡のような、作業として意味の
無いものは書かせない。特定のメールを素材から外したいときは
`MAIL_EXCLUDE_QUERY` に Gmail の検索条件を足す（例: `-label:private`）。

送信メールを使わない場合は `INCLUDE_SENT_MAIL: false` にする。

## セットアップ（15分ほど）

### 1. Apps Script プロジェクトを作る

1. [script.google.com](https://script.google.com) →「新しいプロジェクト」
2. プロジェクト名を「株主日報」などにする
3. 左の ⚙️「プロジェクトの設定」→「`appsscript.json` マニフェスト ファイルをエディタで表示する」に**チェック**

### 2. ファイルを貼り付ける

エディタ上で、このフォルダの 3 ファイルを同じ名前で作って中身を貼る。

| ファイル | 作り方 |
|---|---|
| `appsscript.json` | 既にあるので中身を**丸ごと差し替え** |
| `Code.gs` | 既にある `コード.gs` の中身を差し替え（ファイル名は `Code.gs` に変更） |
| `Config.gs` | 「＋」→「スクリプト」で新規作成 |

### 3. Calendar の詳細サービスを有効にする

左メニュー「サービス」→「＋」→ **Google Calendar API** を追加（識別子は `Calendar` のまま）。
`appsscript.json` を貼っていれば既に有効になっていることもある。

### 4. `Config.gs` を自分用に直す

最低限、次の 2 つだけ確認すれば動く。

```js
CALENDAR_IDS: ['primary'],   // 自分のメインカレンダーだけで良ければこのまま
MINUTES_FOLDER_IDS: [],      // ↓ 次項参照。設定を強く推奨
```

**議事録フォルダの指定（推奨）**
Google Meet の文字起こし・メモは、Drive の **「Meet Recordings」** フォルダに保存される。
そのフォルダを開いたときの URL

```
https://drive.google.com/drive/folders/1AbCdEfGhIjKlMnOpQrStUvWxYz
                                        └──── これがフォルダ ID ────┘
```

を `MINUTES_FOLDER_IDS: ['1AbCdEfGhIjKlMnOpQrStUvWxYz']` のように入れる。

- **指定した場合**: そのフォルダ内の当日分の議事録を、予定に紐づかないものまで残らず拾う
- **空のままの場合**: ドライブ全体を「会議名との一致」だけで検索する（取りこぼしが出やすい）

### 5. 動作確認

関数の選択欄で **`previewDigest`** を選んで実行。初回は Google の認可画面が出るので許可する
（「このアプリは確認されていません」→「詳細」→「安全ではないページに移動」で進む。自作スクリプトのため）。

実行ログに、その日の予定と議事録が並べば成功。メールはまだ送られない。

次に **`sendDailyDigest`** を実行すると、自分宛に素材メールが届く。

### 6. 毎日の自動実行をオンにする

関数の選択欄で **`createDailyTrigger`** を 1 回実行する。
`Config.gs` の `TRIGGER_HOUR`（既定 19）の時間帯に毎日走るようになる。
止めたいときは `deleteTriggers` を実行。

## 毎日の使い方

1. 19 時ごろ届く **「【日報素材】2026年09月09日(水)」** というメールを開く
2. 本文を全選択してコピー
3. **Claude アプリ**に貼り付けて送信 → 日報が返ってくる
4. **内容を確認**する（下の「送信前チェック」）
5. LINE で株主に転送

### 送信前チェック

素材はフィルタせず全部渡している。最後の関門は人間なので、次の3点だけ見る。

- [ ] 未確定の**資金調達・人事・係争**が書かれていないか
- [ ] 他社との**未締結の交渉**が実名で出ていないか
- [ ] 金額・日付が素材どおりか（Claude が丸めていないか）

Claude の出力末尾に `※要確認:` がついている項目は、判断が必要なものとして別掲される。

## 関数の一覧

| 関数 | 用途 |
|---|---|
| `sendDailyDigest()` | 素材メールを送る（トリガーから呼ばれる本体） |
| `previewDigest()` | メールを送らず、素材をログで確認する |
| `sendDigestFor('2026-09-08')` | 特定の日を指定して送り直す |
| `createDailyTrigger()` | 毎日の自動実行を設定する |
| `deleteTriggers()` | 自動実行を止める |

## 設定項目

`Config.gs` の `CONFIG`。

| キー | 既定値 | 意味 |
|---|---|---|
| `CALENDAR_IDS` | `['primary']` | 対象カレンダー。部門カレンダーの ID も追加できる |
| `RECIPIENT` | `''` | 素材メールの宛先。空なら自分自身 |
| `DAY_OFFSET` | `0` | 0=当日 / 1=前日。翌朝に送るなら 1 |
| `MINUTES_FOLDER_IDS` | `[]` | 議事録フォルダ ID。空ならドライブ全体を検索 |
| `INCLUDE_ALL_DAY` | `false` | 終日予定も含めるか |
| `INCLUDE_SENT_MAIL` | `true` | Gmail の送信履歴を素材に含めるか |
| `MAIL_MAX_COUNT` | `40` | 素材に含める送信メールの上限件数 |
| `MAIL_BODY_CHARS` | `200` | メール本文の冒頭を何字取り込むか。0 なら宛先と件名のみ |
| `MAIL_EXCLUDE_QUERY` | `''` | 素材から除くメールの Gmail 検索条件 |
| `SKIP_DECLINED` | `true` | 自分が欠席回答した予定を除外するか |
| `SEND_WHEN_EMPTY` | `false` | 予定 0 件の日もメールを送るか |
| `MAX_DOC_CHARS` | `12000` | 議事録 1 本あたりの取り込み上限 |
| `MAX_TOTAL_CHARS` | `60000` | 素材全体の上限 |
| `TRIGGER_HOUR` | `19` | 自動実行の時刻 |

## 議事録の探し方

1 つの予定に対して、次の順で議事録を探す。

1. **予定の添付ファイル** — Meet が会議後に付ける文字起こし・メモ、手動で添付した Doc
2. **Drive 検索** — 当日〜翌日に更新された Google ドキュメントのうち、**会議名を含む**もの
   （Meet は `会議名 (2026-09-09 at 10:00 GMT+9) - Transcript` のように命名するため一致する）
3. **紐づかなかったぶん** — `MINUTES_FOLDER_IDS` を指定している場合のみ、
   どの予定にも一致しなかった議事録を「予定に紐づかなかった議事録」として末尾にまとめる

会議名を後から変えると 2 では一致しない。3 の保険が効くので、フォルダ指定を推奨している。

## テスト

GAS を使わず、整形ロジックだけを Node で検証できる（依存パッケージなし）。

```
node shareholder-report/test/run.js
```

## 権限について

スクリプトが求める権限は次のとおり。書き込み系は Gmail の送信のみ。

| 権限 | 用途 |
|---|---|
| カレンダー **閲覧** | 予定の取得 |
| Gmail **閲覧** | 送信履歴の取得（`INCLUDE_SENT_MAIL: true` の場合） |
| ドライブ **閲覧** | 議事録ドキュメントの取得 |
| 外部リクエスト | ドキュメント本文をテキストとして書き出す Drive API の呼び出し |
| Gmail **送信** | 素材メールを自分宛に送る |
| トリガー管理 | 毎日の自動実行の設定 |
