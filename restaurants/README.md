# 🍽️ 友メシ帳

友達から教えてもらった **おすすめレストランをメモして管理する**、自分専用の食べログ帳。
iPhone のホーム画面に追加して、ネイティブアプリのように使える単一ファイルの PWA です。

## できること

| 機能 | 内容 |
|---|---|
| 🍽️ **リスト** | お店の一覧。「行きたい / 行った」、ジャンル、友達で絞り込み。店名・エリア・メモ・友達名で検索。並び替え（追加順 / 店名 / エリア / 評価 / 訪問日 / 予算） |
| ➕ **追加・編集** | 店名・ジャンル・エリア・教えてくれた友達・おすすめメモ・夜の予算（食べログの表記のまま）・電話番号・住所・食べログ URL。訪問後は訪問日・5段階評価・感想を記録 |
| 📋 **貼り付けで一括登録** | 友達から届いたメッセージをそのまま貼り付けると、店名（1行目）・電話番号・住所・食べログ URL・予算（`予算 ¥15,000〜¥19,999` の行）を自動で読み取り、残りをメモとして登録。`----` の行で区切れば複数軒をまとめて登録。エリアは住所から、ジャンルは店名・メモから自動判定 |
| 🎲 **ランダム提案** | 「行きたい」お店（絞り込み中ならその中）から 1 軒をランダムに提案 |
| 🔎 **食べログ** | 登録した食べログ URL を開く。未登録なら店名＋エリアで食べログ検索を開く |
| 🗺️ **地図** | Apple マップ / Google マップで開く。住所があれば住所で、無ければ店名＋エリアで検索（設定で切替） |
| 📤 **共有** | お店の情報（店名・ジャンル・エリア・メモ・食べログリンク）をテキストで共有 |
| 👥 **友達** | 紹介してくれた友達ごとに、教えてもらったお店と訪問状況をまとめて表示 |
| ⚙️ **設定** | 地図アプリの選択、JSON エクスポート／インポート（マージ・置き換え）、全削除 |

## ☁️ 家族と共有する（同期）

設定 → 共有 で同じ合言葉を入れた iPhone どうしで、リストが自動で同期されます。
追加・編集・削除が相手にも反映され、電波がないときは iPhone 内のデータで動き、つながったときに同期します。
同期サーバーは Cloudflare 上で動きます（セットアップは [`sync-worker/README.md`](../sync-worker/README.md)）。

## Claude で整形してから登録する

友達のメッセージが「西麻布 うし松」のように店名だけのときは、Claude アプリで一括登録の形式に整えてから貼り付けます。

1. 📋 の画面で「Claude 用の依頼文をコピー」を押す
2. Claude アプリに依頼文を貼り、その下に友達のメッセージを貼って送信
3. 返ってきた結果（食べログ URL・電話・住所・夜の予算入り）をコピーし、📋 の「メッセージ」に貼って登録

## 食べログとの連携について

食べログには公開 API がないため、アプリからお店情報やレビューを自動取得することはできません。
食べログアプリで「共有 → コピー」した店舗ページの URL を貼り付けておくと、「食べログ」ボタンで直接開けます。

## iPhone での使い方

1. GitHub Pages などで公開した URL（例: `https://<ユーザー名>.github.io/iphone/restaurants/`）を **Safari** で開く
2. 共有ボタン → **「ホーム画面に追加」**
3. アイコンから起動するとフルスクリーンのアプリとして使えます（オフライン対応）

## データについて

- データは**この端末のブラウザ内**（localStorage）に保存されます。共有（同期）を有効にしたときだけ、自分の Cloudflare 上の同期サーバーにも保存されます。
- 機種変更やバックアップには、設定画面の **エクスポート / インポート（JSON）** を使ってください。
  エクスポートは iOS の共有シート経由なので「ファイルに保存 → iCloud Drive」が使えます。
