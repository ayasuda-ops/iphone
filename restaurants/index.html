友達ごとに、教えてもらったお店をまとめて表示します。名前をタップすると詳細を開けます。

☁️ 共有（同期）

同じ合言葉を入れた iPhone どうしで、お店のリストが自動で同期されます（例: 夫婦で共有）。
サーバー URL
接続すると、この iPhone のお店がサーバーに送られ、相手のお店と合わさります。
同期中…
共有中は、追加・編集・削除が相手の iPhone にも反映されます。

地図アプリ

お店の詳細から「地図」を開くときに使うアプリ。住所があれば住所で、無ければ店名とエリアで検索します。

食べログ

食べログには公開 API がないため、このアプリからお店の情報やレビューを自動取得することはできません。
食べログの店舗ページ URL を登録しておくと「食べログ」ボタンで直接開けます。URL 未登録なら店名＋エリアで食べログ検索を開きます。

バックアップ

データはこの端末のブラウザ内に保存されます（共有中はサーバーにも保存）。機種変更やバックアップには JSON のエクスポート／インポートを使ってください。
iCloud に残す手順：「エクスポート」→ 共有シートで「ファイルに保存」→ iCloud Drive の好きなフォルダを選択。
iPhoneでの使い方: Safariで開く → 共有 → 「ホーム画面に追加」でアプリのように使えます。

📋 貼り付けで一括登録

🤖 店名だけのメッセージなら Claude で整形
依頼文をコピーして Claude アプリに貼り、その下に友達のメッセージを貼って送信。返ってきた結果をコピーして、下の「メッセージ」に貼り付けます。
友達から届いたメッセージをそのまま貼り付けてください。お店ごとに ---- の行で区切ると複数軒をまとめて登録できます。
各お店の 1 行目を店名として、電話番号・住所・食べログ URL を自動で読み取り、残りの行はメモになります。
